Privacy Policy

Effective November 7, 2026

al-assistant is a single-user personal application. Its only user is its developer and operator, Nick Polizzi, and the only Google account it accesses is the developer's own.

Data access and use

  • Gmail: read-only access, used to search and read the developer's own messages.
  • Google Calendar: read and write access, used to view, create, and update the developer's own events.
  • Google Drive: read-only access, used to search and read the developer's own files.

Storage and sharing

  • All processing happens on the developer's privately operated hardware.
  • Google user data is not sold, shared with, or transferred to any third party.
  • Google user data is not used for advertising, profiling, or training of machine-learning models.
  • OAuth credentials are stored locally on the developer's hardware with restricted file permissions.

Deletion and contact

Access can be revoked at any time from the developer's Google account permissions page, and local credentials can be deleted at any time. Questions: nick.polizzi@gmail.com.
